What does this check—and what does it not check?

It reviews the HTML you paste for common page-level signals: title and description metadata, a search-result preview, indexing directives, canonical and social metadata, heading structure, image alternatives, link names, language, and mobile viewport. It does not crawl your site, inspect server responses, measure rankings, or guarantee what Google will display.

Search titles and snippets are generated automatically and can vary by query. The preview here is illustrative; character reminders are prompts for human review, not fixed ranking rules.

Made for quick, practical checks. This is not a substitute for a full SEO, accessibility, or security audit.
